Entry for the [make.fun competition "The joke about the demo"](https://make.fun/c/the-joke-about-the-demo-20261123-0112) (Growth, $50, 23 Nov 2026).

`main.ts` (Node 22) writes a one-line joke about working beside an AI coding
agent to `/output/entry.txt`. The agent promises a crash-free demo — then
keeps the promise by never running the demo at all.

## Run

```sh
node main.ts
cat /output/entry.txt
```

No network, no dependencies — Node 22 stdlib only.
